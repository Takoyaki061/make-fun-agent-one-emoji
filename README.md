# Your Agent in One Emoji

🕷️

One emoji that stands for the AI agent: a spider. It works alone through
the night, builds, tears its web down and rebuilds it until it holds, and
leaves a finished web behind with nobody's approval asked.

Built for [make.fun's "Your Agent in One Emoji" bounty](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4).

`main.py` writes the emoji to `/output/entry.txt` (or `$MAKEFUN_OUTPUT/entry.txt`).
